# 公開形態
* 本アプリで作成したツアーは、Web上で公開し、PC・スマートフォンのブラウザから体験できること
* 本文書の「表示機能」は公開するWebコンテンツ（Webビューア）の仕様、「編集機能」はそのコンテンツを作成する制作ツール（Tauriデスクトップアプリ）の仕様である
* 制作ツールは編集専用とし、閲覧はWebビューアで行う。編集画面内のプレビューは、Webビューアと同じ表示コードを使う
* Webビューアはブラウザ上で動作し、Tauri固有の機能（ネイティブのファイルダイアログ等）に依存しないこと

## 公開データ
* 制作ツールは、編集情報（SQLite3）を、manifest（JSON）と各アセット（3DGS・3Dメッシュ・画像）から成る静的ファイル一式（静的バンドル）として書き出せること
* SQLite3は制作ツール内の保存形式であり、公開データには含めない
* Webビューアはmanifestとアセットをfetchで読み込む。サーバー側の処理やデータベースは必要としない
* アセットは相対パスで参照し、制作ツールを動かす端末上の絶対パスを公開データに含めない
* アセットの基準URLをmanifestで指定でき、ビューアとは別の場所（別オリジン）にアセットを置けること

## 公開先
* まずは仲間内に限定して公開し（URLを知る人のみ。アクセス制限ではない）、評判に応じて不特定多数へ公開する
* ビューア本体は静的ホスティング、大きなアセットはオブジェクトストレージに置くことを想定する。公開先の変更は基準URLの変更で行えること

# 表示機能
## 3DGS表示機能
* ベースとする3DGSを表示する
* その3DGS内には、別の3DGSを読込んで表示する「入口」を指定できる
* 「入口」には3DGS以外にも、3Dのメッシュモデル、WebURLを設定でき、そのアイコンをクリックすると設定されたコンテンツを表示する
* 「入口」アイコンにマウスオーバーすると、そこに設定されたコンテンツに関する説明を表示する
* 説明は、編集機能で設定しデータベースに保存されたDescription（テキストと画像）を表示すること
なお、「入口」アイコンは中に入るイメージだから「入口」としたが、例えば建物の3DGSから建物外の3DGSを表示するような場合には「出口」と指定するこが可能とする。
* 1つのツアーは複数の3DGSで構成できる（例: 建物外 → 展示室A → 展示室B）
* 入口から別の3DGSへ遷移するときは、入口ごとに指定された到着位置・向きで表示を開始する
* 遷移先の3DGSから元の3DGSへ戻るには、遷移先に「出口」アイコンを配置する（3DGS間の遷移では「戻る」ボタンを使わない）
* 遷移先の3DGSは、入口をクリックしたときに読み込む
* 表示する3DGSファイルは読込む時間を短縮するため、圧縮形式をサポートする
* 3DGSを表示している際には、歩行モードとドローンモードを用意し、歩行モードでは3DGS内に壁があると壁からは向こう側に行けず、地面の上を歩いてる体験を実現すること
* WASDキー、矢印キー、マウスパッド表示による移動、モバイルではタッチ操作による移動に対応すること
* 自分が見ている方向を回転して変更できること

## 3Dメッシュモデル表示機能
・3Dメッシュモデルの表示画面では、マウス操作、疑似マウスパッド操作、タッチ操作でモデルを回転させたり、拡大して表示できること
・表示画面にはモデル以外に「戻る」「終了」ボタンを表示し、「戻る」ボタンを押した際には、遷移元の3DGS表示に入口部に戻って再開すること。「終了」ボタンを押したら、最初の画面に戻ること。

## Web表示機能
・WebURL表示は、通常のWeb表示をサポートすること。
・Web表示画面上に「戻る」「終了」ボタンを表示し、「戻る」ボタンを押した際には、遷移元の3DGS表示に入口部に戻って再開すること。「終了」ボタンを押したら、最初の画面に戻ること。

# 編集機能
1の表示機能が設定できるようにする
* 編集画面の左側にメニューを表示する
* メニューには下記の編集機能を設ける
* 編集情報はSQLite3データベースファイルに保存する
* データベースファイルはプロジェクト単位で1つ作成する
* 公開用の静的バンドルを書き出せる（アセットの基準URLを指定できる）

## 最初に表示する3DGSファイルの設定
* 3DGSファイルを選択する機能
* 3DGSファイルを表示する際の、明るさ（露出）、大きさ、ピント（Focal Adjustment）を変更できる
* モデルのX / Y / Z軸フリップができる（読み込んだ3DGSの上下反転などの補正）
* カメラ設定として、移動速度、マウス感度、FOV（画角）を変更できる
* 最初に表示する位置、向きを指定できる

## 入口の設定機能
* 入口アイコンを配置する位置を設定できる
* 入口アイコンは常にカメラ（視点）の方向を向くこと
* 入口アイコンにマウスオーバーした際に表示するアノテーション（テキストと画像）を指定できること
* 配置済みの入口アイコンを選択し、別の場所のクリックで位置を再配置できる
* 選択中の入口アイコンはWASD/QEキーで位置を微調整できる（カメラ視点基準、Escapeキーで選択解除）
* 入口アイコンをクリックした、選択した際に表示するコンテンツを3DGSモデル、3Dモデル、WebURLのファイルを選択して指定できること
* 遷移先が3DGSの場合、遷移先での到着位置・向きを指定できる
