# splat-tour

3D Gaussian Splatting（3DGS）で撮影した空間を、ブラウザ（PC・スマートフォン）で歩き回れるバーチャルツアーのWebビューアです。空間内に置いた入口アイコンにマウスを乗せる（スマホではタップする）と解説（テキスト・画像）が表示され、開くと別の3DGS・3Dモデル・Webページへ移動できます。

ツアーの内容は `manifest.json`（JSON）に書きます。このリポジトリには、ビューアのほか、manifest を手で書くための補助（座標の表示・床合わせ）、3DGS や 3Dモデルの変換、公開用フォルダの作成の道具が入っています。GUI で manifest を作る制作ツールは、別のプロジェクトで開発しています。

[try-spark](https://github.com/aktnk/try-spark) での実装経験をもとに、ゼロから再実装しています。

## 技術スタック

- Vite + TypeScript
- Three.js
- [@sparkjsdev/spark](https://sparkjs.dev/)（3DGSレンダラー）
- nipplejs（タッチ操作用バーチャルジョイスティック）

## セットアップと起動

```bash
npm install
cp tours/sample/manifest_sample.json tours/sample/manifest.json   # 初回だけ（manifest.json は git に入らない）
npm run dev             # http://localhost:5190（tours/sample を表示。?debug=1 で座標表示）
npm run build           # 型チェックと dist-viewer/ への公開用ビルド
npm run tour:bundle     # ビューア + manifest + 使っているアセットを dist-publish/ にまとめる
```

manifest の書き方、座標の調べ方、アセットの変換、公開方法は [tours/README.md](./tours/README.md) を参照してください。

## ビューアの操作

ツアーを見る人の操作です。

| 操作 | PC | スマホ |
|---|---|---|
| 見回す | ドラッグ | ドラッグ |
| 移動 | WASD・矢印キー（Q / E で上下、Shift で速く） | 左下のジョイスティック |
| 入口の説明を見る | アイコンにマウスを乗せる | アイコンをタップ |
| 入口を開く | アイコンをクリック | もう一度タップ、または説明の「開く」 |

- **入口アイコン**: コインの形です。色と記号で種類が分かります（青「→」: 入口、橙「←」: 出口、緑「3D」: 3Dモデル、紫「Web」: Webページ）。近くのアイコンは大きく、遠くのアイコンは小さく表示します。遠くても小さくなりすぎず、クリックしやすい大きさは保ちます。壁などの向こうにあるアイコンは隠れます。
- **説明のポップアップ**: タイトル・説明文と、移動先の画像1枚を「移動先: 〈シーン名／3Dモデル／サイト名〉」付きで表示します。画像は作者が選んだ `thumbnail` を優先し、なければツールが作った `autoThumbnail`（到着位置で撮った画像など）です。外部サイトの Webページはそのサイトの OGP 画像だけを表示します。説明文の中の URL はリンクになり、新しいタブで開きます（ポップアップの上にマウスを移しても消えないので、クリックできます）。
- **目次（☰）**: 画面左上のボタンで開きます。シーンと、各シーンの入口を一覧で表示します。
  - シーンを選ぶと、そのシーンの最初の位置へ移動します。
  - 入口を選ぶと、アイコンを開いたときと同じ画面へ移動します。3Dモデル・Webページは、その入口があるシーンへ移動してから開きます。
  - 今いるシーンには「（いまここ）」が付きます。「×」、画面の外側、Esc で閉じます。
- **見どころ**: 目次（☰）に並びます（シーンの中にアイコンは出しません）。マウスを乗せると（スマホは1回目のタップで）説明と眺めのサムネイルが出て、選ぶと同じシーンの中の決められた位置・向きへカメラが滑らかに移動します。
- **初期位置**: 右下のボタンで、そのシーンに入ったときの位置と向きに戻ります。撮影範囲の外のノイズに迷い込んだときに使います。
- **3Dモデル・Webページの画面**: 下のバーの「戻る」で、開いた入口の前に戻ります。Webページには「新しいタブで開く」もあります。埋め込みを拒否するサイトは、こちらで開いてください。

### 制作の補助（`?debug=1`）

URL に `?debug=1` を付けると、右上に manifest を手で書くためのパネルが出ます。使い方の詳細は [tours/README.md](./tours/README.md) を参照してください。

- **現在の視点**: `initialView`（最初の位置）や `arrival`（到着位置）に貼れる位置と向き
- **クリックした位置**: 入口の `position` に貼れる座標
- **床合わせ**: 床を3点クリックして、傾いた 3DGS を水平にする `transform`
- **今の画面を画像で保存**: 入口の `autoThumbnail`（移動先の画像）用に、今の画面（3Dモデルの画面ではそのモデル）をアイコン抜きで 480×270 の画像にしてダウンロードします。ファイル名には撮った日時が付くので（例: `main-hall-view-20261015-231502.webp`。3Dモデルは `-model-`）、同じシーンで何枚撮っても重なりません。`assets/` に置き、そのパスを `autoThumbnail` に書きます。

`?scene=<シーンの id>` を付けると、そのシーンから開きます。

## 他のプロジェクトから使う

ビューアの部品と manifest の型・検証は、パッケージとして読み込めます（TypeScript のソースのまま提供しているので、Vite などのバンドラーで使ってください）。パッケージに入るのはビューアのソースと画面の HTML・CSS だけです（`package.json` の `files`）。`tours/` やツールは入りません。ツアーのデータを `node_modules` の中に置くと `npm install` のたびに消えるので、必ずその外に置いてください。

```ts
import { startTour, setupScene } from "splat-tour";
import { parseManifest, type Manifest } from "splat-tour/manifest";
```

`startTour()` は、ビューアの画面の部品（`viewer/index.html` の要素）が id で見つかることを前提にしています。同じ画面を別のアプリの中に作るときは、HTML と CSS も読み込めます（Vite の場合）。

```ts
import "splat-tour/viewer.css";
import viewerHtml from "splat-tour/viewer.html?raw"; // <body> の中身を自分のページに入れる（<script> は除く）
```

- [ ] 歩行モード（壁・地面）/ ドローンモード
- [x] シーンごとの設定：回転補正（床合わせ）、大きさ、露出、Focal Adjustment、移動速度、FOV、最初の表示位置・向き、移動できる範囲
- [x] 入口アイコン（コイン型、壁で隠れる、遠いほど小さく・最小と最大のサイズあり）とホバー表示（テキスト＋画像）。スマホはタップ
- [x] 入口の遷移（3DGS / 3Dメッシュ / WebURL）、メッシュ・Web表示画面、「戻る」「初期位置」
- [x] 3DGS間の遷移（入口ごとの到着位置・向き、遷移先の「出口」）
- [x] 目次（左のサイドバーにシーンと入口を一覧。選ぶとそこへ移動）
- [x] 見どころ（目次から選ぶと、同じシーン内の視点へカメラが滑らかに移動。`target.type: "view"`。目次でマウスを乗せると説明とサムネイル）
- [x] 入口のポップアップに移動先の画像1枚（作者の `thumbnail` を優先、なければ自動の `autoThumbnail`。外部サイトは OGP 画像）
- [x] スマホの発熱対策（静止時は描画・処理を停止、30fps・解像度 1.5 倍上限）
- [x] manifest の手書き補助（`?debug=1` の座標表示・床合わせ、`?scene=` で任意のシーンから開く）
- [x] 公開データ形式の決定（3DGS: RAD SH1 ストリーミング、3Dモデル: 最適化 GLB）と変換ツール
- [x] 公開用フォルダの作成（Cloudflare Pages 向け、RAD の分割）
